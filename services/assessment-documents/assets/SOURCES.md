# Certificate font sources and instances

The mother platform's Manrope and Sora remain the body and display sources. Noto Sans is used only when certificate text contains glyphs absent from Manrope. The upstream variable binaries are unmodified; rendering uses renamed static instances generated by `../prepare_fonts.py` with pinned FontTools 4.67.0. This avoids variable-font instancing at PDF runtime, which produced missing visible glyphs in raster QA. Weight is pinned to 400 (body/fallback) and 600 (Sora display); every other axis is pinned to its upstream default. Timestamps are preserved for reproducible binaries. Original copyright notices and SIL Open Font Licenses are retained and embedded in the documents.

`font-instances.json` records each original source hash, instance hash, axes and tool version. `python services/assessment-documents/prepare_fonts.py --check` reconstructs all three instances in memory and checks exact bytes/provenance without editing assets. Neither this tool nor the renderer edits mother-platform assets.

The extended-Cyrillic Noto instance is embedded in full, not subsetted: runtime subsetting discarded composite outlines while text extraction still appeared correct. A native regression checks exact complete embedded-font bytes; the mixed-language long-field sample is separately rasterized and visually inspected. Ordinary Manrope/Sora subsets retain the mother typography without that fallback cost.
