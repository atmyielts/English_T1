# AI provider availability and private diagnostics

On 2026-10-10 the production `OPENROUTER_MODEL` digest matched `google/gemma-3-27b-it:free`. The public OpenRouter endpoints API returned an empty endpoint list for that exact model, and the public model catalog omitted it. Owned Writing requests returned `provider_unconfirmed`; their concurrent duplicate was rejected. No saved-feedback success was claimed.

The non-secret shared model setting was changed to `google/gemma-4-31b-it:free` after confirming an active endpoint, JSON response support, and zero prompt/completion prices. All other secret digests were unchanged. Supabase refreshed all 89 function versions; function identities, JWT settings and active statuses remained unchanged. Before/after downloaded source hashes for Writing, Speaking, account closure, parent reports and the six financial functions matched exactly. This configuration change affects every endpoint that uses the shared OpenRouter model. It does not change the API key or any payment configuration.

The next owned Writing test still returned `provider_unconfirmed`. Its two synthetic actors were closed using the published account-closure endpoint; cleanup verification passed. Model availability alone therefore does not establish provider authentication, feedback quality or service readiness.

Writing and Speaking now emit a private structured `coaching_provider_failure` event through an optional reporter. Its fields are the service name, validated request UUID and an allowlisted failure code. HTTP errors include only their status, while timeouts, transport, invalid JSON and rubric validation receive fixed labels. Unknown exceptions receive `provider_unknown`. Logs never contain the provider key, response body, essay, transcript, user identifier, arbitrary message or stack trace. Reporter failures cannot prevent finalizing an uncertain receipt. Customer responses and conservative request accounting remain unchanged, and no provider retry or paid fallback is introduced.

Confirm the actual HTTP/validation failure before another configuration or provider change. Then qualify real saved feedback, duplicate/replay behavior, account closure, and the published recovery screens. Free endpoints remain subject to provider rate limits; zero token prices are not an availability guarantee.

Rollback uses the previous reviewed coaching bundle or disables new dispatch with zero service caps, while preserving additive SQL and saved-result retrieval. Do not restore the retired model, legacy unlimited Speaking scorer, or general-purchase premium allowance.
