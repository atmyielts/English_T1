# Playbook catalog and page recovery

Both SAT and TOEFL Playbooks linked Modules to an unpublished format-overview page. A failed page request kept the loading heading and spinner visible indefinitely. The public Modules route now reads the actual published catalog, shows honest empty collections, and links to returned module slugs. Premium guide listings contain public metadata; existing page access checks still apply when opened. Invalid collections and unsafe/reserved slugs fail with retry instead of inventing content.

Content and catalog reads have a twelve-second deadline, cancel on route changes, and offer explicit retry after failure. Missing content has a terminal unavailable state and a catalog link. Stale content is hidden across route and account changes; canceled responses cannot redirect or replace another page. Analytics failure does not interrupt reading. Paid dashboard empty catalogs link to the public catalog, and diagnostic output no longer fabricates a format-overview recommendation. TOEFL's incorrect SAT diagnostic heading is corrected; practice links use the existing TOEFL simulator /practice route instead of the unconfigured practice subdomain.
