# Original SAT result feedback

After question publication changes, learners must still see the outcome, expected answer and explanation recorded when their drill was scored. The result endpoint now explicitly identifies an owned immutable receipt. The results screen displays its saved scorer feedback and original choice labels rather than deriving an answer from a current bank key. Wrong selected choices have both an incorrect label and distinct styling; malformed or missing recorded outcomes show an explicit unconfirmed state, preserving the answer without a green correctness cue. No AI call is made to display saved explanations.

Older scores without an original receipt retain their saved score and answers in an explicitly limited-history view. The service does not replace missing original prompts with edited current questions. A receipt storage outage remains a retryable error, rather than silently switching history sources. Unsubmitted owned questions still redact the entire private correct property. Customer scores, answers, rewards and receipts are not rewritten.

The SAT card-grid CSS also had bank-filter declarations accidentally inserted into the grouped grid selector. The repair separates those rules, restoring desktop card columns and the existing one-column mobile layout. An actual dashboard browser scenario verifies computed grid layout at390/1280px.
